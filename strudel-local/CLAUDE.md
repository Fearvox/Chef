# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

This is a **Strudel** live coding music playground. Strudel is a browser-based music live coding environment — a JavaScript port of TidalCycles. The upstream repo is at `https://codeberg.org/uzu/strudel` (GitHub mirror is archived, do NOT use it).

## Architecture

Strudel is a **pnpm workspaces monorepo**. Key directories after cloning:

| Directory | Purpose |
|-----------|---------|
| `packages/core` | Pattern engine — `Pattern`, `queryArc`, `Hap` (event) |
| `packages/mini` | Mini-notation parser (peggy PEG grammar) |
| `packages/transpiler` | User code → AST (acorn) → Strudel calls (escodegen) |
| `packages/webaudio` | Default WebAudio output |
| `packages/tonal` | Scales, chords, notes |
| `packages/repl` | REPL web component |
| `packages/osc` | OSC output |
| `packages/midi` | MIDI output |
| `website/` | Astro-based REPL site + docs |

## Commands

```bash
pnpm i              # install all workspace deps
pnpm dev            # start REPL dev server (runs jsdoc-json first)
pnpm test           # vitest — all tests
pnpm lint           # eslint (quiet mode)
pnpm codeformat     # prettier — format all
pnpm format-check   # prettier — check only
pnpm check          # full CI: format-check + lint + test
pnpm osc            # start OSC server
```

## Core Concepts

- **Pattern**: Pure function `queryArc(begin, end) → Hap[]`. All music is patterns.
- **Hap**: An event with time span + value (note, sample, params).
- **Mini-notation**: String DSL for rhythms — `"c3 [e3 g3]*2"` → pattern of notes.
- **Transpiler**: Converts user code shortcuts (double-quoted strings → `m()` calls).
- **Scheduler**: Queries pattern every ~50ms, dispatches events to WebAudio with ~100-150ms latency.

## Key Rules

- Package manager is **pnpm** — never use npm or yarn.
- License is **AGPL-3.0**.
- Formatting: Prettier. Linting: ESLint 9. Tests: vitest.
- Publishing: always `pnpm publish`, never `npm publish`.
- Mini-notation parser is generated by peggy — edit `.pegjs` source, not generated output.
- The repo was moved to Codeberg. Do NOT reference GitHub URLs for the upstream project.
